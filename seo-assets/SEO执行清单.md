# 李满园 SEO 执行清单

## 第一步：部署网站上线（今天就做）

### 方案 A：腾讯云静态网站托管（推荐，免费，国内访问快）

1. 打开 https://cloud.tencent.com/
2. 搜索"静态网站托管"（CloudBase）
3. 开通服务（有免费额度：5GB存储 + 5GB流量/月）
4. 创建环境 → 进入静态网站托管
5. 上传整个 `limanyuan-site` 文件夹
6. 获得默认域名（形如 `xxx.tcloudbaseapp.com`）
7. 如果已有域名，绑定自定义域名（如 `limanyuan.com`）

### 方案 B：GitHub Pages（免费，但国内访问慢）

1. 创建 GitHub 仓库 `limanyuan-site`
2. 推送代码到仓库
3. Settings → Pages → 选择 main 分支 → 保存
4. 获得 `username.github.io/limanyuan-site` 域名

## 第二步：搜索引擎提交（部署后立即做）

### 百度站长平台 (ziyuan.baidu.com)
1. 注册/登录百度站长平台
2. 添加网站：`https://你的域名/`
3. 验证所有权（选择 HTML 标签验证，把验证码填到 index.html 的 `<meta name="baidu-site-verification">` 中）
4. 提交 sitemap.xml
5. 使用"普通收录"提交首页URL
6. 使用"快速收录"（如有权限）

### 360 站长平台 (zhanzhang.so.com)
1. 添加网站并验证
2. 提交 sitemap

### 必应站长平台 (bing.com/webmasters)
1. 添加网站
2. 提交 sitemap

### 搜狗站长平台 (zhanzhang.sogou.com)
1. 添加网站并验证
